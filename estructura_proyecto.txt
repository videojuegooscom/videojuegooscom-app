ESTRUCTURA DEL PROYECTO · VideojuegosZaragoza (tienda online de electrónica)
=============================================================================

Qué es: tienda web hecha con TypeScript, React Native y Expo Router 6, exportada como web estática y publicada en
Vercel; base de datos, cuentas y almacenamiento en Supabase; cobros con Stripe; conexión firmada con VeoAura (el
programa de gestión del stock y las facturas).

Cómo se comprueba:
  - Tipos:        npx tsc --noEmit
  - Estilo:       npm run lint
  - Compilación:  npm run build   (genera dist/)
  - Pruebas:      pruebas/todas.mjs (todas); pruebas/perfil-datos.mjs dist <carpeta capturas> <SECCION> (pantallas en
                  el navegador, con datos ficticios); pruebas/pago-api.mjs (pagos); pruebas/perfiles-sql.mjs (base de datos).

Cada archivo de código empieza con una cabecera: Archivo, Función, Para qué sirve, Conectado con, Utilizado por,
Dependencias y Estado (ACTIVO o CANDIDATO_A_ELIMINAR). Los candidatos y los archivos nuevos están en
documentacion/registro-archivos.md.

ZONA DELICADA = inicio de sesión, pagos, administradores, conexión con VeoAura o configuración: no se toca sin
revisión del dueño.

Formato de cada línea:  archivo | función | conectado con | utilizado por | estado
